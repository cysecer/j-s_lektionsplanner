# data/

## common-passwords.txt

Lower-cased, de-duplicated passwords of 15–128 characters that appear in public
breach corpora. New passwords matching an entry are rejected
(NIST SP 800-63B, "blocklist"). Shorter entries are omitted because the
minimum password length is 15.

Source: [SecLists](https://github.com/danielmiessler/SecLists) (MIT License),
`Passwords/Common-Credentials/`:
`Pwdb_top-1000000.txt`, `xato-net-10-million-passwords-1000000.txt`,
`100k-most-used-passwords-NCSC.txt`, `Language-Specific/German_common-password-list-top-1000000.txt`,
`Language-Specific/French-common-password-list-top-20000.txt`.
